# OrbitEye
# Sobre o projeto
O OrbitEye é uma plataforma web desenvolvida para a Global Solution FIAP 2026.
O projeto tem como objetivo apresentar uma solução tecnológica inspirada em tecnologias espaciais para auxiliar no monitoramento ambiental, permitindo o desastre naturais e análise de informações ambientais.

A prosposta busca demonstrar como o uso de dados, sensores e monitoramento inteligente pode contribuir para a preservação ambiental e para a tomada de decisões mais rápidas e eficientes.

# Funcionalidades
- Página incial
- Navegação entre as seções
- Área sobre o projeto
- Dashboard de monitoramento ambiental
- Galeria de imagens
- Quiz interativo com perguntas sobre sustentabilidade
- Formulário de contato
- Alterações de temas visuais
- Botão de retorno ao topo
